# Alix Barreaux - QA Automation Engineer (SDET) Portfolio

This is the personal portfolio website of **Alix Barreaux**, showcasing experience and projects as a QA Automation Engineer (SDET).
The site highlights skills in Cypress, CI/CD, test architecture, and system design, and demonstrates real  world QA projects.

## Features

- Responsive, mobile first design
- Dark theme with gradient accents
- Smooth scroll and active section highlighting
- Project showcase with GitHub links
- Contact section with email, LinkedIn, and GitHub links
- Scroll progress bar and "back to top" button
- Accessible skip to content link

## Tech Stack

- HTML5, CSS3, JavaScript
- Tailwind CSS
- Alpine.js for interactive elements
- Font Awesome icons
- Hosted images and project screenshots

## Projects Featured

- **Meetic Full Manual QA Suite**: Sample bug reports, test planning, exploratory testing.
- **Wirk - Cypress Automation Strategy**: End to end Cypress suite for web application flows.
- **Invoice Flow**: Fullstack application demonstrating automation first architecture.
- **Open Source Contributions - Stronghold Crusader**: GitHub PR contributions to the Unofficial Crusader Patch.
